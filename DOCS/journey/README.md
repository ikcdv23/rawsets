# Journey docs

Resúmenes curados de sesiones largas y consecuentes con Claude. No son transcripts literales — son la **historia destilada**: qué se discutió, qué se decidió, qué se aprendió y qué quedó pendiente.

**Distinción con [`DOCS/adr/`](../adr/)**: los ADRs son el **resultado** (la decisión formalizada con sus alternativas). Los journey docs son el **camino** (cómo se llegó allí, qué tropiezos hubo, qué momentos pedagógicos pasaron). Un ADR debería poder leerse sin el journey; un journey complementa los ADRs con narrativa.

**Cuándo escribir uno**: cuando una sesión cierra varias decisiones de fondo o tiene momentos pedagógicos que el yo-del-futuro agradecerá releer. Sesiones cortas o tareas mecánicas no necesitan journey.

**Formato**: `YYYY-MM-DD-titulo-slug.md`.
