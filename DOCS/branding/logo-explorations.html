RAWSETS

Seis direcciones distintas para el wordmark, usando tipografías display futuristas reales y construcciones tipográficas personalizadas. Cada bloque muestra la misma palabra en variante clara y oscura para evaluar contraste y peso en ambos contextos.

00 · Reference reading

Lo que leo de tu referencia.

Las tipografías que enseñaste (Anero, Blackbox, Sentex, Mayhem) comparten un ADN común: geometría pura, cortes diagonales agresivos, ausencia de curvas suaves, y un aire pixel-display de terminal/arcade. No es Apple-clean. Es techno underground / tech avant-garde.

// Atributos visuales

Geometría pura

Letterforms construidos con planos rectos. Diagonales sustituyendo curvas. Espacio negativo agresivo. Contornos angulares. Sin remates ornamentales.

// Asociaciones culturales

Techno underground

Berghain, Boiler Room, gaming/cyberpunk (Cyberpunk 2077, Death Stranding), moda avant-garde (Y-3, A-COLD-WALL, Off-White), packaging técnico (sneakers limitados).

// Lo que NO eres

Mass market / wellness

Wellness suave, fitness comercial, motivacional, gamificado, mass market. La tipografía debe alejarte explícitamente de esos territorios.

// Riesgos a evitar

Clichés del género

El sci-fi cliché (Orbitron mil veces usado). El "tech" sin alma (Helvetica + acento de color). El brutalism vacío que no comunica. La fuente custom amateur.

07 · Sistema

Variantes que el logo necesita.

Un logo no es una imagen, es un sistema. Sea cual sea la dirección que elijamos, necesitamos al menos cuatro versiones para no improvisar después.

// Variante

Wordmark completo

"RAWSETS" en horizontal. La versión principal. Va en landing, splash, top de la app.

// Variante

Monograma / símbolo

"R" o "RS" o un símbolo derivado. Para app icon, favicon, social avatar, watermark.

// Variante

Versión inversa

El wordmark en blanco sobre fondo oscuro y en oscuro sobre fondo claro. Asegurar contraste.

// Variante

Versión mínima / mark only

Solo el acento (el cuadrado/punto violeta) para esquinas, watermarks, loading states.

08 · Recommendation

Mi recomendación.

Dirección 01 (Zen Dots) o Dirección 06 (Custom geometric)

Las dos te dan exactamente el lenguaje visual de tus referencias. La diferencia es coste y autenticidad:

  • Zen Dots es la opción arranquemos ya. Tipografía gratuita, lista para usar, casi indistinguible del look de tus referencias para alguien que no es diseñador profesional.
  • Custom geometric es la opción marca verdadera. Te da algo único, no replicable buscándolo en Google Fonts. Pero exige varios días de trabajo afinando las 7 letterforms hasta que respiren bien.

Camino pragmático: empezar con Zen Dots como "logo provisional v0.1". Permite arrancar app, branding y comunicación inmediatamente. Cuando el producto esté maduro (Fase 2), invertir tiempo en custom geometric como evolución.

Próximos pasos

Cuando elijas dirección:

  1. Cerramos la tipografía y el acento (punto / cuadrado / underscore / slash).
  2. Diseñamos el monograma/símbolo derivado para app icon y favicon.
  3. Producimos el set completo de variantes (claro/oscuro/mínimo) en SVG editable.
  4. Actualizamos el brand book con la decisión final.
  5. Pensamos taglines alineados con la tipografía elegida.
